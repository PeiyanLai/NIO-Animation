# 强制规则一页清单（动手前过一遍，交付前再过一遍）

> 这是 SKILL.md 里所有「（强制）」条款的索引卡。每条的完整判据、反例和踩坑
> 记录在 SKILL.md 对应章节——这页只负责「别忘了」，不负责「怎么做」。
> **拆给 agent 的任务书必须整页附上本清单。**

## 布局与信息展示

- [ ] **信息卡不落画面四角**——所有动画、所有图层，无一例外。四角禁区尺寸
      与断言参照 `bag-data.ts` 的 `CORNERS`（190×105 四块）。
- [ ] 信息卡不压主体、不压 SAFE 区；贴主体的卡走 18–60 带宽（大叙事卡免检）。
- [ ] 引导线长度上限：大卡 640 / 小卡 440。
- [ ] 标注类叠加（logo、圆点、引导线落点）必须在**渲染合成结果**上闭环校验，
      不许只在素材图上量。

## 配色与环境

- [ ] 车内物件的配色必须与座舱内饰适配（全局规则，用户明令）。
- [ ] 背景/环境要具象到「一眼可辨」：车库像车库、山路像山路。
- [ ] 品牌色见 `references/nio-colors.md`。

## 选材与视角

- [ ] 先判需求是**车外**还是**座舱**：车外 → ES9 库；座舱 → ES8 库。
      需求点名车型时以需求为准。
- [ ] 挑图第一判据：**主体所在的位置在图里拍得到**（宠物坐二排就不能用
      只拍前排的图）；第二判据：主体朝向贴合机位。
- [ ] 视角选定后，图就定死了——同一台蔚来车全仓库同视角必须同一张图。
- [ ] 第三方车必须明显不是蔚来车（尺寸/颜色/造型三维同时拉开）。
- [ ] 拿到俯视/侧视图先验是不是正投影（`assert-orthographic.py`）。

## 生物主体

- [ ] 需求涉及宠物 → 一律用宠物素材库的真实画像
      （`assets/pets/`，调用规则见其 README），不画矢量动物。
- [ ] 动作必须符合常识：狗走路要迈腿（关节腿剪纸），舱盖开合看「一条缝」。

## 几何与验证

- [ ] 主张要有几何证据：位置、尺寸、遮挡关系全部来自标定换算，不许目测拍脑袋。
- [ ] 用户圈选/标注的位置，用画面内已知坐标的锚点做换算，不做语义猜测。
- [ ] 叙事结论写成**可失败的断言**并全时间轴跑过（bag 全时间轴断言是范例）。
- [ ] 语义锚点位置只测一次，之后引用常量；换相机必须重反解照片锚定的控件。

## 素材合规与同步

- [ ] 新素材入库必须登记 `photos/*/approved-asset-manifest.json`
      （来源、授权、水印/营销文案检查）。
- [ ] 资产**复制不引用**：工程内联 ts 与 `assets/` canonical 拷贝用
      `assert-assets-in-sync.py` 校验，改素材必跑。

## 交付闭环

- [ ] 改完组件必须重跑 `build-player.py`（否则发出去的是旧快照）→
      `assert-self-contained-html.mjs --fragment` → 无头浏览器零报错 →
      Artifact **同址**发布（带 url 参数，别开新链接）。
- [ ] GIF 走 `make-gif.py`，1440×810 / 6fps 起步，清晰度优先于体积。
- [ ] 默认交付 HTML，不默认出 MP4（成本约束，用户点名才导）。
- [ ] 在公司/外部 agent 里交付：HTML **推送为对话附件**（可点开/查看/下载），
      且右上角带「高清 GIF 一键下载」（每场景一键 + 全部打包 zip，
      `build-player.py --gif` 内嵌预渲染 GIF）。
      验收要把 HTML 下载到本地打开做——Artifact 查看器沙箱拦下载是正常现象。

## 拆 agent 干活

- [ ] 几何标定、交付发布、commit 留主线；组件改造给 agent。
- [ ] 任务书写死可改/禁改文件清单，**并整页附上本清单**——
      宠物模式步骤卡落四角返工，就是任务书漏附规则造成的。
