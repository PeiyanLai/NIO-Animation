# 运行环境需求（拿去和平台方对表用）

> 本文回答两个问题：**skill 在什么环境下能完整跑通**；**环境缺哪块时，
> 能力退化到什么程度**。文末附「问平台方的问题清单」，逐项拿到答案就能
> 判断 skill 要不要调整。所有版本号为实测跑通值（2026-08，Linux x64）。

## 两个 skill 的要求截然不同

| skill | 环境要求 |
|---|---|
| `req-clarify`（需求澄清） | **几乎为零**：能对话 + 能读写文件即可。任何 agent 环境都能跑 |
| `remotion`（动画制作） | 下表全套（分完整/降级两档） |

以下全部针对 remotion skill。

## 一、完整产线的环境清单

### 1. 操作系统与硬件

| 项 | 要求 | 实测值 | 说明 |
|---|---|---|---|
| OS | Linux x64 | Linux 6.x | macOS/Windows 未验证，首跑先过 preflight |
| 内存 | **≥4GB 可用** | 16GB | 渲染 concurrency=2 峰值约 2–3GB；不足会 OOM(exit 137) |
| 磁盘 | **≥2GB 可写** | — | node_modules 约 870MB + 产物（单页 1–30MB）+ 临时帧 |
| CPU | 无特殊要求 | — | 核多渲得快，2 核也能跑（时间×2） |

### 2. 运行时与依赖

| 项 | 最低要求 | 实测值 | 用途 |
|---|---|---|---|
| Node.js | ≥18 | v22.22.2 | Remotion / esbuild / 断言脚本 |
| npm | 可用 | — | 装 remotion 全家桶（见网络节） |
| Remotion | **≥4.0.5xx（硬要求）** | 4.0.509 | 低版本不支持新 Chromium（无 `--chrome-mode` 参数） |
| Python | ≥3.9 | 3.11.15 | 产线脚本 |
| Pillow (PIL) | 任意近版 | 12.3.0 | 抠图/GIF 调色板/图像量测 |
| numpy | 任意近版 | 2.4.6 | 抠图矩阵运算 |
| scipy | 任意近版 | 1.17.1 | 连通域/补洞（ndimage）——**抠新图才需要**，只做动画可缺 |
| esbuild | 任意近版 | 0.28.2 | build-player 打包（npm 装） |
| **Chromium/Chrome** | **较新版本（无旧 headless）** | 141.0 | Remotion 渲染引擎。路径用 `REMOTION_BROWSER` 环境变量指定，**必须预装**（外网受限时 Remotion 自己下载会失败） |
| ffmpeg | 不需要系统装 | — | Remotion npm 包自带 compositor；preflight 会验证真实可执行性 |

### 3. 网络

| 场景 | 需要什么 |
|---|---|
| **首次安装** | 能访问 npm registry（官方或公司镜像均可）装 `remotion@4.0.5xx` 全家桶 ≈870MB。**完全无网时**：需要平台预装好 node_modules，或允许离线包导入 |
| **日常渲染/打包** | **零外网**——浏览器预装、素材全部 base64 内联、无任何运行时外链 |
| skill 更新 | zip 导入模式零网络；update.py 模式需 api.github.com（可选） |

### 4. agent 能力面（比软件环境更常卡住的地方）

| 能力 | 用途 | 缺了会怎样 |
|---|---|---|
| Bash 执行 | npm/node/python 全部产线命令 | **完全跑不了**，硬要求 |
| 文件读写 | 源码/产物 | 硬要求 |
| **长命令容忍** | 单条命令 2–20 分钟（GIF/MP4 渲染） | 命令超时上限 <10min 且无后台任务机制 → 长渲染会被杀。**问清超时上限** |
| **多模态读图** | 目检渲染帧（关键验证环节） | 降级：只能靠断言+用户目检，返工轮次增加（见降级表） |
| 文件外发 | 交付 HTML（附件/链接/路径三级） | 走交付降级序列第 3 级（给绝对路径）；三级全无 = 交付失败 |
| 接收用户图片 | 需求截图/概念图/圈选反馈 | 缺了则位置类反馈只能靠文字描述，纠偏效率大降 |

### 5. 权限

无需 root；只要工作目录可写。不访问系统敏感路径。

## 二、能力降级表（环境缺块时如实告知用户）

| 缺失项 | 剩余能力 |
|---|---|
| 无 Chromium / Remotion 装不上 | **不能渲染**：只能写/改组件代码，HTML·GIF 由能渲染的一方产出后由它分发（分工模式，SKILL 步骤 0） |
| 无 npm 网络且未预装 node_modules | 同上（不能渲染） |
| 无 scipy | 不能抠新图；已入库素材的动画制作不受影响 |
| 无多模态读图 | 断言照跑，目检环节交给用户（发帧图请用户确认），迭代变慢但能走通 |
| 命令超时 <10min | still/断言/打包能跑；GIF 逐章分开渲可勉强；MP4 基本不可行 |
| 无文件外发（三级全无） | 制作能完成但交付失败——**这是平台必须解决的一项** |

## 三、验证方法（拿到环境先跑这两步）

```bash
bash scripts/preflight.sh        # 一键自检:node/remotion/chromium/ffmpeg/PIL
# 冒烟渲染(约 30s,出一张 1920×1080 PNG 即环境可用):
cd animations && npx remotion still src/index.ts Title /tmp/smoke.png --frame=10 \
  --browser-executable=$REMOTION_BROWSER --chrome-mode=chrome-for-testing
```

## 四、问平台方的问题清单（逐项要答案）

1. 运行环境是什么 OS/架构？内存和磁盘配额多少？
2. 有没有 Node.js？版本？npm 能不能访问 registry（官方或公司镜像）？
3. 有没有 Python3 + Pillow/numpy/scipy？没有能不能装？
4. **有没有预装的 Chromium/Chrome？路径是什么？**（填给 REMOTION_BROWSER）
   没有的话能不能预装一个较新版本？
5. **单条命令的执行超时上限是多少？有没有后台/异步任务机制？**
6. agent 能不能看图（多模态）？
7. agent 有没有把文件发进对话的工具？没有的话能不能给用户可点的下载链接？
   再没有，用户能不能直接访问 agent 的工作目录？
8. 用户能不能在对话里发图片给 agent？
9. 沙箱是否持久（node_modules 装一次能不能留住），还是每次会话重置？
   ——每次重置 + 无网 = 必须预装依赖，务必问清
10. 有没有全局的产物大小限制（交付 HTML 5–30MB）？

拿到答案后对照第一、二节：全绿 → skill 原样可用；缺渲染/读图/外发 →
按降级表明确告知能力边界；**第 5、7、9 三项是最常见的隐形杀手，优先确认**。
