# 宠物上下车坡道 · 需求实现详述（逆向自成品）

## 1. 功能定位与教育目标

后备箱斜坡架让中大型犬（尤其老年犬）自己走上车。叙事策略是**先立问题再给方案**：
用整整一章演示「不用架子会怎样」（跳不上去+伤关节），方案的价值自然成立。

## 2. 舞台与视角

车尾侧视矢量场景（车尾轮廓 + 电动尾门 + 装载口），犬 = **真实边牧照片剪纸**。
走路用**关节腿剪纸**（四条腿独立贴图绕腿根枢轴对角步态摆动）——「狗要真实
迈腿」是用户点名要求。

## 3. 主体清单

| 主体 | 呈现方式 | 关键约束 |
|---|---|---|
| 边牧 | 照片剪纸 + 关节腿 | 肩高 570mm 与车高 1870mm 同尺换算（比值 0.305±3% 有断言）；senior 版压饱和+步态放慢 |
| 电动尾门 | 矢量 | **铰链在车顶后缘**，抬起 72°（开到位门板近水平后伸）——铰链位置画错是高危项 |
| 斜坡架 | 概念矢量 | 两段展开，顶端挂钩搭门槛；坡长 2000mm |
| 高度标尺 | 双向箭头 | 地面 → 装载口下沿 787mm |

## 4. 章节详述（每章 5 拍）

**第一章 · 打开后备箱 · 看清高度差（10s）**
犬走到车尾 → 电动尾门抬起装载口打开 → 犬抬头看：装载口高过它的肩 →
从地面量到装载口下沿 → **离地 ≈787mm，相当于跨一整级台阶**。

**第二章 · 不用架子会怎样（9s，问题章）**
不装架子只能整只跳 → 后腿蓄力起跳 → **最高点还差约 25%，前爪够不到装载口**
→ 老年犬跳得更低基本上不去 → 落地冲击集中在前肢关节，反复跳伤关节。
（起跳轨迹是抛物线动画，最高点与装载口的差距画对比线）

**第三章 · 装上斜坡架（11s）**
斜坡架折叠收在后备箱（**收纳位置待定义→概念件**）→ 取出放到车尾地面 →
两段展开、顶端挂钩往门槛上一搭 → 标出坡长 2000mm、装载口高 787mm →
**sin 23° = 787/2000——坡度就是这么来的**（直角三角形三边全标出）。

**第四章 · 犬自己走上去（12s，情绪章）**
犬自己走到坡脚 → 四足踩坡面身体与坡面平行（**关节腿真实迈步 7.4 秒长镜头**）
→ 越过门槛走进后备箱 → 在装载口里趴下 → 不用抱、不用跳。

## 5. 关键数值与几何主张

| 数值 | 出现 | 说明 |
|---|---|---|
| 787mm | 一/三章标尺 | 装载口离地高（产品数据） |
| 2000mm | 三章 | 坡长——**直接决定坡度，需求必须给** |
| sin23°=787/2000 | 三章 | 几何关系画在画面上，可信度来源 |
| 差约 25% | 二章 | 起跳最高点 vs 装载口——断言「够不到」必须成立 |
| 570/1870=0.305 | 全片 | 犬肩高/车高，同尺换算断言 |

## 6. 断言

「跳不上去」→ 起跳最高点 < 装载口高（**够到了这一章叙事就废了**）；
犬掌全程不穿坡面/地面；≥2 掌支撑；坡度关系式成立；比例断言。
